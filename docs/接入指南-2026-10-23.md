## 〇、先记住分工（一句话）

**core 管注册 / 门禁 / 记忆 / 确认；不执行你的工具。** 你的工具执行体在自己代码里，
返回值用 `Result` 四级形状。core 给你的是：命名消歧、权限门禁、ID 家隔离、记忆、会话记账、确认令牌。

---

## 一、实现工具组（10 分钟）

三件事：给契约号、给来源 ID、描述工具组。继承 `ToolGroupProvider.Simple` 即可：

```java
public final class HelloProvider extends ToolGroupProvider.Simple {
    public HelloProvider() {
        super(Version.CORE_API, "hello-demo");     // 契约号 + 来源 ID（非空才有资格）
    }
    @Override
    public ToolGroupProvider.Descriptor describe() {
        return new ToolGroupProvider.Descriptor(
                "echo", "示例/入门", "回声示例工具组（教程用）",
                "接入指南配套示例。",
                ToolRegistry.Availability.NORMAL,
                List.of(new ToolRegistry.Tool("echo", "回显文本",
                        "echo(text) → 原样返回 text", Map.of("type", "object"))));
    }
}
```

要点（红线全文见概念地图 §三《接入红线》，此处只引不抄）：
- **你只给组短名**——全名 `local:hello-demo:echo` 由装载器拼（红线 2：provider 不构造限定名）；
- 简介（summary）与工具详解（usage + params）**必填**，注册时校验，缺了整组拒载；
- `coreApi` 与 `Version.CORE_API` 不等 → 拒载（红线 5：宁拒不猜兼容）。

## 二、装配（5 分钟，顺序即依赖）

```java
Ids ids = Ids.at(root);                               // ① 存储根（全部 ID 家的父目录）
Ids.Caller caller = new Ids.Caller("model-01");       // ② 调用方身份（红线 6：core 注入不可伪造）
ToolRegistry registry = new ToolRegistry();           // ③ 注册表
ProviderLoader loader = new ProviderLoader(registry); // ④ 装载器（依赖 ③）
Permissions perms = Permissions.defaultAll(registry); // ⑤ 门禁（依赖 ③）
```

- `defaultAll` = **全权限**，教程图省事用它；**生产请 `Permissions.fromFiles(registry, input, bundled)`**
  （语义：给了 input 用 input，否则用自带；热更新不回溯）；
- 之后按需构造能力对象，全部吃 `(ids, caller)` 两级：`TodoStore` / `NoteStore` / `MemoryStore` /
  `RawLog` / `Rollup` / `Corrections` / `SessionGate` / `ConfirmGate`；
- **core 不执行你的工具**：注册放行后，执行体是你自己的代码，返回 `Result`。

## 三、装载与启动报告（5 分钟）

```java
String full = loader.load(new HelloProvider(), Names.SourceType.LOCAL);
System.out.println(full);                    // → local:hello-demo:echo
List<String> report = StartupReport.render(
        registry, registry.names(), loader.issues(), null, null);
```

- `load` 返回 null = 拒载，详情在 `loader.issues()`——**看报告，别猜**；
- 启动报告三件套：来源分布、消歧表、WARN 汇总——上线前应当全绿无未知项；
- 模组卸载走 `loader.unload(type, sourceId)`（幂等，记 WARN 不静默）。

## 四、查询注入面（3 分钟）

```java
registry.briefs();                    // 简表：注入模型用（不含详解）
registry.help("echo", Map.of());      // 详解：按需取（缺名报「工具不存在」）
registry.search("回声", null);         // 关键词搜索；禁用对象只搜名字
```

- 短名撞车（同名多来源）不猜：`help` 会报歧义候选，**用全名或在权限文件配别名**；
- 别名规则：歧义短名可配别名定向；唯一短名拒收别名（遮蔽了本来明确的名字）。

## 五、调用与 Result 四级（5 分钟）

自带能力的调用（你的工具同形状）：

```java
TodoStore todos = new TodoStore(ids, caller);   // 工作目录自动挂 caller 的家
Result r = todos.add("读一遍接入指南");          // → Result.Ok(...)
```

四级形状（红线 1、4）：`Result.Ok` 照常给数据 · `Result.Warn` 数据+描述 · `Result.Severe`
**部分**数据+描述（带伤运行）· `Result.Error` 无数据只有原因。**非 OK 必须带描述**（构造期直接抛）；
**失败走 Error 或抛异常，禁止把失败文本包进 Ok**。

## 六、常见坑（按踩中频率）

| 坑 | 后果 | 正解 |
|---|---|---|
| 自己拼限定名 | 拼错/冒名，装载器不认 | 只给组短名与 sourceId |
| 忘写 usage/params | 整组拒载 | 工具详解必填（红线补充约定） |
| `defaultAll` 直接上生产 | 全权限 | `fromFiles` + 权限文件 |
| 把失败包成 Ok 数据 | 假成功 | `Result.error(...)` 或抛异常 |
| 短名歧义硬选一个 | 行为漂移 | 全名 / 别名定向 |
| 期望 core 执行你的工具 | 想当然 | 执行体在你这边，返回 `Result` |
