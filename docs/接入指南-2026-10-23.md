## 〇、先记住分工（一句话）

**core 管注册 / 门禁 / 记忆 / 确认；不执行你的工具。** 你的工具执行体在自己代码里，
返回值用 `Result` 四级形状。core 给你的是：命名消歧、权限门禁、ID 家隔离、记忆、会话记账、确认令牌。

---

## 一、实现工具组（10 分钟）

三件事：给契约号、给来源 ID、描述工具组。继承 `ToolGroupProvider.Simple` 即可：

```java
public final class HelloProvider extends ToolGroupProvider.Simple {
    public HelloProvider() {
        super(Version.CORE_API, "hello-demo");     // 契约号 + 来源 ID（非空才有资格）
    }
    @Override
    public ToolGroupProvider.Descriptor describe() {
        return new ToolGroupProvider.Descriptor(
                "echo", "示例/入门", "回声示例工具组（教程用）",
                "接入指南配套示例。",
                ToolRegistry.Availability.NORMAL,
                List.of(new ToolRegistry.Tool("echo", "回显文本",
                        "echo(text) → 原样返回 text", Map.of("type", "object"))));
    }
}
```

要点（红线全文见概念地图 §三《接入红线》，此处只引不抄）：
- **你只给组短名**——全名 `local:hello-demo:echo` 由装载器拼（红线 2：provider 不构造限定名）；
- 简介（summary）与工具详解（usage + params）**必填**，注册时校验，缺了整组拒载；
- `coreApi` 与 `Version.CORE_API` 不等 → 拒载（红线 5：宁拒不猜兼容）。

## 二、装配（5 分钟，标准入口=门面）

```java
SnowLeopard core = SnowLeopard.bootstrap(root, SnowLeopard.Options.allowAll());
SnowLeopard.CallerScope scope = core.forCaller("model-01");   // 进入调用方的家（红线 6）
```

**门面默认值清单**（S3：默认即政策，每个默认一句话立场）：

| 项 | 默认 | 立场 |
|---|---|---|
| 权限 | **无默认**，`Options.allowAll()` 与 `Options.fromFiles(input, bundled)` 必须显式二选一 | 全开是危险默认，不许静默继承；生产用 fromFiles（热更新不回溯） |
| 压缩器 | 直通（不调 LLM，摘要=原文） | 缺省可跑但**启动报告点名**；LLM 压缩经 `withCompressor` 注入 `Compressor` |
| 会话预算 | 无上限（`SessionGate.Budget.unlimited()`） | 收束由宿主决定；`withBudget` 显式收紧 |
| 配置来源描述 | 按权限选择自动生成 | 进启动报告；`withConfigSrc` 可覆盖 |

- root 级（共享）：`core.ids()` / `core.registry()` / `core.loader()` / `core.permissions()`；
  caller 级（每模型一份）：`scope.todos()` / `notes()` / `memory()` / `rawLog()` / `rollup()` /
  `corrections()` / `session()` / `confirm()`——工作目录自动挂 `scope.home()`；
- reload/unload 等控制点保留在组件层（`core.permissions().reload(...)`、`core.loader().unload(...)`），门面只转发；
- **core 不执行你的工具**：注册放行后，执行体是你自己的代码，返回 `Result`。

> **进阶：手动装配（门面的展开式）**——需要自定义装配时按依赖顺序自己拼：
> `Ids.at(root)` → `new Ids.Caller(id)` → `new ToolRegistry()` → `new ProviderLoader(registry)`
> → `Permissions.defaultAll/fromFiles` → 各能力 `new XxxStore(ids, caller)`。
> 门面只调公开 API、无特权步骤，两条路径同行为（examples 的 HelloManualMain 常绿保活证明）。

## 三、装载与启动报告（5 分钟）

```java
String full = core.loader().load(new HelloProvider(), Names.SourceType.LOCAL);
System.out.println(full);                    // → local:hello-demo:echo
System.out.println(core.startupReport());    // 含门面默认值提示（S3 可观测）
```

- `load` 返回 null = 拒载，详情在 `core.loader().issues()`——**看报告，别猜**；
- 启动报告三件套：来源分布、消歧表、WARN 汇总——上线前应当全绿无未知项；
- 模组卸载走 `core.loader().unload(type, sourceId)`（幂等，记 WARN 不静默）。

## 四、查询注入面（3 分钟）

```java
core.registry().briefs();                  // 简表：注入模型用（不含详解）
core.registry().help("echo", Map.of());    // 详解：按需取（缺名报「工具不存在」）
core.registry().search("回声", null);       // 关键词搜索；禁用对象只搜名字
```

- 短名撞车（同名多来源）不猜：`help` 会报歧义候选，**用全名或在权限文件配别名**；
- 别名规则：歧义短名可配别名定向；唯一短名拒收别名（遮蔽了本来明确的名字）。

## 五、调用与 Result 四级（5 分钟）

自带能力的调用（你的工具同形状）：

```java
SnowLeopard.CallerScope scope = core.forCaller("model-01");  // 工作目录自动挂 scope.home()
Result r = scope.todos().add("读一遍接入指南");               // → Result.Ok(...)
```

四级形状（红线 1、4）：`Result.Ok` 照常给数据 · `Result.Warn` 数据+描述 · `Result.Severe`
**部分**数据+描述（带伤运行）· `Result.Error` 无数据只有原因。**非 OK 必须带描述**（构造期直接抛）；
**失败走 Error 或抛异常，禁止把失败文本包进 Ok**。

## 六、常见坑（按踩中频率）

| 坑 | 后果 | 正解 |
|---|---|---|
| 自己拼限定名 | 拼错/冒名，装载器不认 | 只给组短名与 sourceId |
| 忘写 usage/params | 整组拒载 | 工具详解必填（红线补充约定） |
| `defaultAll` 直接上生产 | 全权限 | `fromFiles` + 权限文件 |
| 把失败包成 Ok 数据 | 假成功 | `Result.error(...)` 或抛异常 |
| 短名歧义硬选一个 | 行为漂移 | 全名 / 别名定向 |
| 期望 core 执行你的工具 | 想当然 | 执行体在你这边，返回 `Result` |
